## 如何使用本仓库

1. **跟踪你的学习进度**：你可以 Fork 本仓库并在 Markdown 中将 `- [ ]` 改为 `- [x]`，作为整个双学位五年学习周期的任务清单。
2. **先读课件教材，再动手实践**：
   - 每门课优先阅读 `课本电子版及资料/` 下的讲义、教材与历年试卷；
   - 编程与实验课程强烈建议**独立完成**后再对照 `作业/` 中的实验报告、仿真工程（`.ms13` / `.mlx` / `.SLDPRT` / `.py` / `.cpp`）和课程论文进行查漏补缺。
3. **双学位时间管理建议**：
   - 低年级打牢**微积分、线代、大学物理与 C++**，这是后续所有信息工程核心课的共同底座；
   - 中高年级进入**信号与系统 → 数字信号处理 → 通信原理**与**电路 → 模电/数电 → 电磁场与微波**两条主干线，同时利用英语专业在学术写作（`英语技术写作`）和文献阅读上的优势，反哺英文原版教材（*Calculus*、*Sears Physics*、*Pozar Microwave Engineering*、*Oppenheim DSP*、*Haykin Communication Systems*）与英文科技论文撰写。

## 大体积文件与仓库使用说明

- GitHub 对单文件存在 **100 MB** 硬限制（部分高清扫描教材、实验演示视频与 EDA 软件压缩包超过该阈值）。
